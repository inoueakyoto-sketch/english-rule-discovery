# RULE FINDER｜英語のしくみ発見 v0.1.5 no-pattern-hint + POS candidate

中学生が英文法の規則を「説明される前に少し違う文へ出会う → 自分なりに分類する → 新しい規則を知る」の順で発見し、その後は短い練習で定着させる、スマホ優先の静的Webアプリです。

## v0.1.5 の変更

- 問題画面左上に出ていた `SV` / `SVO` / `UNKNOWN` / `SVC + ?` などの文型ヒントを削除
- 問題画面では問題番号だけを表示し、発見前に文型を推測できる情報を出さない
- 「単語」を開いたとき、日本語訳に加えて品詞・まとまりを表示
  - 代名詞 / 固有名詞 / 名詞 / 名詞のまとまり
  - 一般動詞 / be動詞
  - 形容詞
  - 代名詞（目的格）
  - 副詞 / 前置詞＋名詞のまとまり など
- v0.1.4 のブラウザ内学習記録を引き継ぐ

## 4つの入口

ホームから次の4つを選べます。

1. **発見をつづける**
   - SV → SVC → SVO → SVOO → SVOC → M の順に、未知を1つずつ投入
   - 未発見の役割名は先に表示しない
   - 正誤にかかわらず、未知の形へ出会った後で解説する
2. **5問だけ練習する**
   - 発見済みルールだけを出題
   - 本人にはランダムに見えるが、内部では「最近間違えた・まだ練習回数が少ない・しばらく出ていない」規則を優先
   - 同じ規則が続きすぎないよう重みを調整
   - 5問で必ず一区切りにし、結果を表示
3. **S・V・O・Cを学ぶ（ROLE LAB）**
   - S＝名詞系 / V＝動詞系 / O＝名詞系 / C＝名詞・形容詞系、という基本対応を整理
   - 代名詞・名詞のまとまり・目的格・助動詞＋動詞・進行形などをパターン別に表示
   - 不定詞・動名詞・that＋文など「あとで増える形」も、基本と区別して掲載
   - teacher のように同じ名詞でも S / O / C と役割が変わる比較を掲載
4. **気づきを振り返る**
   - 発見済みルールを自分の気づきとして保存
   - 問題中も1タップで戻れる
   - 練習で間違えたときは「気づきを見て、同じ問題をもう一度」が可能

## 定着データ

各ルールごとにブラウザ内へ以下を保存します。

- 練習回数
- 正解回数 / 誤答回数
- 最後に練習した時刻
- 最後の結果

これらから練習の出題重みを決めます。画面では細かい正答率を前面に出さず、

- これから
- 練習中
- あと少し
- かなり分かってきた
- もう一度

のような言葉で「今の手ごたえ」を表示します。

## 学習フロー

発見モード：

SV → 未習SVC → C解説 → SVO → O解説 → SVOO → SVOC → SVC+M → M解説

各現在文型で3問の安定正解を目安に次の未知パターンを投入します。

練習モード：

発見済みルール → 適応ランダム5問 → 必要なら気づきノート → 同じ問題へ再挑戦 → 5問のまとめ

## GitHub Pages

1. ZIPを展開します。
2. `index.html` がリポジトリの公開ルートに来るよう全ファイルを配置します。
3. VS Codeから `git add .` → `git commit` → `git push` します。
4. GitHub の Settings → Pages で `main` / `(root)` を公開元にします。

ビルド工程やサーバー処理は不要です。
