# RULE FINDER｜英語のしくみ発見 v0.1.6 challenge candidate

中学生が英文法の規則を「説明される前に少し違う文へ出会う → 自分なりに分類する → 新しい規則を知る」の順で発見し、短い練習で定着させ、最後に高校・大学レベルの英文にも挑戦するスマホ優先の静的Webアプリです。

## v0.1.6 の変更

### 難問チャレンジを追加

5文型＋Mまで発見するとホームの「難問にチャレンジ」が開きます。

5問の短いセッションで、必ず次の3種類を含みます。

1. **文型を見抜く**
   - 高校・大学レベルの語彙や長い主語・節を含む英文を、S / V / O / C / M の大きなかたまりに分類
   - 問題中は文型名を表示しない
   - 回答後に初めて `SVO` / `SVOC + M` などを表示
2. **穴埋め**
   - Cだから形容詞、Oの中だから名詞、というように役割と品詞を手がかりに選択
   - 英語試験の語形・空所補充へ接続
3. **並び替え**
   - S → V → O / C の骨組みとMの位置を手がかりに英文を組み立てる
   - 英語試験の語句整序へ接続

### 難しい単語は補助する

難問は語彙力を測るテストではありません。「単語」を押すと、

- 英語
- 日本語の意味
- 品詞
- 必要に応じて文全体の日本語

を確認できます。

### 難問は通常の習得度と別管理

難問の誤答で、SV / SVC / SVO など通常学習の習得表示は下がりません。

- 5問のスコア
- BESTスコア
- 挑戦回数

だけを別に保存します。

## 5つの入口

1. **発見をつづける**
   - SV → SVC → SVO → SVOO → SVOC → M の順に、未知を1つずつ投入
   - 未発見の役割名は先に表示しない
2. **5問だけ練習する**
   - 発見済みルールだけを適応ランダム出題
   - 苦手・久しぶり・練習回数が少ない規則を少し多めにする
3. **S・V・O・Cを学ぶ（ROLE LAB）**
   - S＝名詞系 / V＝動詞系 / O＝名詞系 / C＝名詞・形容詞系を整理
   - 品詞と文の役割を分けて理解する
4. **難問にチャレンジ**
   - 5文型＋M発見後にOPEN
   - 高校・大学レベルの英文、穴埋め、並び替えへ転移
5. **気づきを振り返る**
   - 自分で発見したルールをいつでも確認
   - 問題中でも戻れる

## v0.1.5 から維持している仕様

- 問題画面に `SVO` / `UNKNOWN` などの文型ヒントを出さない
- 「単語」には日本語訳＋品詞を表示
- 共通基礎語彙を学年・学期タグで制御
- スマホ390px前後を主基準
- 中学生が持ちやすい、少し大人っぽいダークネイビー中心のUI
- PWA / GitHub Pages対応
- 既存の学習履歴をv0.1.6へ引き継ぐ

## GitHub Pages

1. ZIPを展開します。
2. `index.html` がリポジトリの公開ルートに来るよう全ファイルを配置します。
3. VS Codeから次を実行します。

```bash
git add .
git commit -m "Update to v0.1.6 challenge"
git push
```

4. GitHub の Settings → Pages で `main` / `(root)` を公開元にします。

ビルド工程やサーバー処理は不要です。

## 現在の制約

通常問題の語彙データは共通基礎語彙の試作です。今後、教科書・学年・学期・Unitごとの語彙データに差し替える前提です。

難問は「学校で未習の語彙や構造があっても、中学で学んだ骨組みの見方を転用できる」ことを体験するための編集済み例題です。大学入試等の過去問転載ではありません。
