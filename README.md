# RULE FINDER｜英語のしくみ発見 v0.1.2 discovery notebook candidate

中学生が英文法の規則を「説明される前に少し違う文へ出会う → 自分なりに分類する → 新しい規則を知る」の順で発見する、スマホ優先の静的Webアプリです。

## v0.1.2 気づきノート

- 右上に「気づき」ボタンを常設し、どの画面からでも発見済みルールを振り返れる
- 問題中にも1タップの「気づき」導線を配置
- SV / SVC / SVO / SVOO / SVOC / Mを、発見した順にノートへ自動保存
- 各ノートに「短い説明・見分けるポイント・例・比較」を掲載
- RULE MAP（発見済みだけ名称を表示）の発見済み項目をタップすると、その気づきへ直接戻れる
- 未発見の文型名はRULE MAP（発見済みだけ名称を表示）に表示せず「？」にして、先の答えを見せない
- ノートを閉じると、解いていた問題や結果画面へそのまま戻れる

## 今回のUI/UX更新

- スマホを主画面として再設計（390px前後を基準）
- 中学生が持ちやすい、少し大人っぽいダークネイビー＋ブルーのプロダクト調UI
- 1画面1課題に近づけ、説明文を短く整理
- 親指操作を意識した下部の操作ドック
- 5文型＋Mの進捗を見せる RULE MAP（発見済みだけ名称を表示）
- 連続正解 STREAK（競争ではなく、自分の安定度のフィードバック）
- 新しい規則に出会ったときだけ画面トーンが変わる NEW RULE 演出
- 対応端末では控えめな振動フィードバック
- 「？」を未習役割として継続採用
- 設定をスマホ向けボトムシート化
- iPhoneのセーフエリアに対応
- `prefers-reduced-motion` に対応

## 学習フロー

SV → 未習SVC → C解説 → SVO → O解説 → SVOO → SVOC → SVC+M → M解説

各現在文型で3問の安定正解を目安に次の未知パターンを投入します。

## GitHub Pages

1. ZIPを展開します。
2. `index.html` がリポジトリの公開ルートに来るよう全ファイルを配置します。
3. GitHub の Settings → Pages でブランチから公開します。
4. 反映後、スマホSafari/ChromeからURLを開きます。

ビルド工程やサーバー処理は不要です。
